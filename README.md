# Lecture Notes

Course notes and self-written lecture note series, University of Michigan.
All notes are written in a rigorous, proof-complete style — full derivations
in LaTeX, not formula sheets.

- **[`mathematics/`](mathematics/)** — course-by-course notes (686 pp total):
  real analysis, multivariable analysis, measure theory, and topology.
- **[`physics/series/`](physics/series/)** — *Lecture Notes in Physics,
  Volumes I–IV* (221 pp combined): one continuous argument from the harmonic
  oscillator through variational mechanics and classical field theory to
  quantum mechanics, with a cross-reference-checked volume build system.
