# Lecture Notes

Course notes and self-written lecture note series, University of Michigan.

## Structure
- `mathematics/` — course-by-course notes (real analysis, multivariable
  analysis, measure theory, algebraic topology, …), written in a
  rigorous, Axler-inspired style: full proofs, not formula sheets.
- `physics/series/` — **Lecture Notes in Physics, Volumes I–IV** (221 pp
  combined): Oscillators → Variational Mechanics → Special Relativity and
  Classical Field Theory → Quantum Mechanics. Standalone `.tex` sources,
  figure-generation scripts, and a cross-reference-checked volume build
  system. See `physics/series/README.md`.
